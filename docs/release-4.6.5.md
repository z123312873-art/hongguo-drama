# 紅果短劇 4.6.5 預發佈

預發佈內部版本為 4.6.5，發行標籤為 `installer-4.6.5-traditional-pre`。正式版仍是 4.6.1，更新器不會把預發佈當成最新版；下載與安裝須自行確認。確認沒問題後，再發佈 4.7 正式版。

## 更新摘要

- 修復紅果短劇無法播放，恢復線上取址
- 修復河馬短劇有集無鎖卻不能播，播放器可切換解析度，畫質最高 720P
- 移除西飯來源，只保留紅果與河馬
- 河馬海報載入更快，首屏更快出現
- 河馬題材標籤整理成複合分類，篩選更清爽
- 觀看紀錄與手機同步更快，並可批次移除紀錄
- 搜尋預設紅果並顯示全部結果，分「標題匹配」與「其他相關」
- 精簡提示文字，修正來源選單顯示

## 說明

紅果短劇改用新的播放接口與簽名取址。先前伺服器對舊簽名回空內容，導致整部劇無法播放；新版本在真實裝置簽名下重新取得可播地址，目錄與搜尋維持原本路徑。畫質的自動與手動選擇策略沒有改變。

河馬短劇改走 App 後端取址，不再於畫面上預先把分集標成鎖定。先前訪客初始化請求被錯誤包裝，取到的又可能是封面圖而非影片，因此看起來沒有鎖定卻無法播放，上方清晰度也不能改。現已修正取址，可播集能直接看；播放器可在自動與 720P 之間切換，畫質上限為 720P，不提供 1080P。若來源沒有下發播放地址，仍會清楚提示需在河馬官方 App 內解鎖，不會假裝已解鎖。河馬目錄沿用網頁後端。

西飯來源已完全移除，只保留紅果（預設）與河馬。先前把西饭設為來源的舊設定、舊收藏與舊播放編號會自動回到紅果，殘留的西饭編號仍可辨識並提示已移除。

河馬海報改用來源的縮圖尺寸、先對當前卡片所在的圖床預連線，並讓前面的海報優先載入、過一段時間未出現時再試原圖，縮短第一屏海報出現的時間；原圖仍是後備，載入失敗會換回原圖或佔位圖。

河馬題材標籤把原本零碎的分類整理成數量較少的複合分類，點選以多個題材編號的聯集篩選，不綁定任何單一短劇。

預發佈用來實測播放與同步。測試時請特別確認紅果影片播放、河馬可播集播放與清晰度切換、海報呈現與搜尋。
