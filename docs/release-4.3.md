# 紅果短劇 4.3（預發佈）

4.3 為 **預發佈**（`installer-4.3-traditional-pre`），不會觸發 4.1 的自動更新，也不取代 4.1 正式版。

## 更新摘要

- 在線播放更快更穩：打開一集通常不到一秒，連續切換集數不再卡住或出現「片源服務沒有返回資料」。
- 下一集會提前準備好，接著看時幾乎不用等。
- 漫畫分類補齊到 140 部；就算某一種查詢沒有結果，也會改用其他方式補足。
- 漫畫閱讀頁底部的「上一話」「返回選集」按鈕，在深色背景下看得清楚。

## 已知限制

- 補齊 140 部漫畫需要一點時間，期間會先顯示已取得的漫畫。
- 若所在網路完全連不到片源服務，仍需要到設定啟用代理。
- 安裝檔未簽章。
