# 紅果短劇 4.3（預發佈）

4.3 為 **預發佈**（`installer-4.3-traditional-pre`），不會觸發 4.1 的自動更新，也不取代 4.1 正式版。4.2 預發佈的內容已全部併入 4.3。

## 更新摘要

- 新增「漫畫」分類：可挑漫畫、選集數閱讀，最多 140 部，並記住上次讀到的地方。
- 漫畫圖片清晰度會隨視窗大小自動調整，1K、2K、4K 螢幕都清楚。
- 漫畫補到 140 部更穩：載入時頁數不再忽多忽少，也不會出現空白頁。
- 漫畫閱讀頁底部的「上一話」「返回選集」按鈕，在深色背景下看得清楚。
- 真人劇、漫劇、AI劇首頁的海報數量與漫畫一致；西飯、河馬首頁至少顯示 40 部。
- 剛開啟時海報出現得更快，不再卡在只有兩排；西飯、河馬的海報會存在本機，切換來源立即顯示。
- 在線播放更快更穩：打開一集通常不到一秒，連續切換集數不再卡住，下一集也會提前準備好。

## 已知限制

- 第一次開啟漫畫分類時，補齊需要一點時間，期間會先顯示已取得的漫畫。
- 若所在網路完全連不到片源服務，仍需要到設定啟用代理。
- 安裝檔未簽章。
