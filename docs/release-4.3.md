# 紅果短劇 4.3

4.3 為 **正式版**（`v4.3` / GitHub Latest）。`windows/4.3-release-*` 分支的 Windows CI 建置後，由 `publish-release-4-3` 工作建立發行：安裝版（NSIS）、`.blockmap`、`latest.yml`（應用內更新必需）與便攜 ZIP。安裝檔未簽章，SHA256 寫在發行說明。發行完成後，4.2 與 4.3 的預發佈（`installer-4.2-traditional-pre`、`installer-4.3-traditional-pre`）會一併移除，4.2 的內容已全部併入 4.3。

## 更新摘要

- 新增「漫畫」分類，最多 300 部，可挑漫畫、選集數閱讀，並記住讀到哪裡。
- 漫畫圖片會提前載入，往下滑幾乎不用等；下一話也會先準備好。
- 按「刷新片單」不再換掉畫面上的漫畫，點分集都能打開。
- 漫畫圖片清晰度隨視窗大小調整，1K、2K、4K 螢幕都清楚。
- 各分類首頁海報更多且數量一致，西飯、河馬首頁至少 40 部。
- 剛開啟時海報出現得更快；西飯、河馬海報存在本機，切換來源立即顯示。
- 在線播放更快更穩，切換集數幾乎不用等。
- 漫畫閱讀頁底部按鈕在深色背景下清楚可見。

## 已知限制

- 第一次開啟漫畫分類時，補齊需要一點時間，期間會先顯示已取得的漫畫。
- 若所在網路完全連不到片源服務，仍需要到設定啟用代理。
- 某部漫畫若來源沒有分集，點開時會提示並從畫面上移除，之後不再補進片單。
- 安裝檔未簽章。
