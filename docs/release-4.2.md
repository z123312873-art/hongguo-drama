# 紅果短劇 4.2（預發佈）

4.2 為 **預發佈**（`installer-4.2-traditional-pre`），不會觸發 4.1 的自動更新，也不取代 4.1 正式版。

## 更新摘要

- 新增「漫畫」分類，位置在「AI劇」之後。海報順序與紅果網站的漫畫分類相同，最多 140 部，下方可分頁切換。
- 點開漫畫先看分集，選了某一話才會載入圖片，可從上次讀到的地方繼續。
- 漫畫圖片清晰度會隨視窗大小自動調整，1K、2K、4K 螢幕都適用。
- 真人劇、漫劇、AI劇的首頁顯示的海報數量，與漫畫一致。
- 西飯、河馬首頁至少顯示 40 部。
- 漫畫載入更穩定，讀取失敗時會自動重試，並說明原因。

## 已知限制

- 第一次開啟漫畫分類時，補齊到 140 部需要一點時間，期間會先顯示已取得的漫畫。
- 安裝檔未簽章。
