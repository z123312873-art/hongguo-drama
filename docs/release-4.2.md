# 紅果短劇 4.2（預發佈）

4.2 為 **預發佈**（`installer-4.2-traditional-pre`），不會觸發 4.1 的自動更新。

## 漫畫分類

- 發現頁分類列在「AI劇」之後新增「漫畫」。海報順序與 `https://hongguoduanju.com/category/comic` 相同（站內 74 部，依分頁順序），不顯示星等與「新劇」；其後以 App 搜尋找到的其他漫畫隨機補齊，總數最多 140 部。補齊用的名單用站內漫畫最常見的標籤當關鍵字蒐集，只收連載 20 話以上、有標籤的作品，同一天內順序固定，結果存在使用者資料夾的 `comic-cache.json`（過期後先顯示舊的、背景更新）。
- 載入順序：上次存檔的片單（立即顯示）→ 站內第 1 頁（首屏）→ 其餘站內分頁（背景、最多 3 個並行、只顯示連續前綴，不會跳頁）→ 補齊名單。畫面上的海報只增不減，更新失敗時保留舊片單並提示。
- 標籤（`src/comicTags.mjs`）：站內約 60 個原始標籤依關鍵字歸成 16 個，一部漫畫可屬於多個；沒有作品的標籤不顯示，最多同時選兩個（需同時符合）。新標籤只要含有關鍵字就會自動歸類，不需改清單。
- 分頁（`src/comicLayout.mjs`）：每頁取整列數，3 到 4 列；尚在載入時，分頁已顯示即將到來的頁數，點到未到的頁面顯示骨架。

## 閱讀

- 點海報只讀取分集目錄（`directory/all_items`），每 50 話一組，標籤取自來源標題（來源會跳號，例如沒有第 2 話）。按一話才讀取該話的圖片清單與圖片。記得讀過的集數與上次讀到的位置（`localStorage`，`src/comicProgress.mjs`），可「繼續閱讀」。
- 圖片由 CDN 的 `novel-pic/<md5>~tplv-resize:<W>:0.webp` 取得，寬度從 360／540／720／900／1080／1440 依閱讀欄寬乘以裝置像素比挑選；視窗放大只會要求更清晰的版本。進入畫面前約 1800px 才載入。約 18% 的圖片在公開 CDN 回 404，會改走已簽章的原圖並在本機以 AES-256-GCM 解密（`comic-image` IPC，Blob 顯示，CSP 的 `img-src` 加入 `blob:`）。
- 閱讀器：上一話／下一話、方向鍵、Esc 返回選集；結尾提供下一話；背景只預取下一話的圖片清單，離開時取消。

## 請求控管（避免連續空回應與裝置被封）

- 所有閱讀 API 經 `src/native/comic-scheduler.js`：點擊優先、預取其次、背景最後；限速約每秒 1.4 次，不同請求共用同一裝置的額度（實測約每 30–50 秒 100 次後開始回空回應）。
- 收到空回應時先帶隨機延遲退避重試；連續 3 次空回應才註冊新的匿名裝置（10 分鐘內最多 3 次、兩次之間至少隔 5 秒），不會連續輪換。
- `reader` 身分（aid 1967）與紅果（aid 8662）的簽章、裝置註冊分開，`src/native/app-source-signing.test.cjs` 以黃金摘要確保紅果原有簽章逐位元不變。
