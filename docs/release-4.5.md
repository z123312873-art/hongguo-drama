## 更新摘要

- 新增「搶先上線日」顯示即將上線解鎖短劇，請多加利用
- 修正首次播放卡頓問題
- 修正來源格式不同時，優化在線播放等待
- 優化線路不穩時，自動接入備用線路

發現頁標題旁邊的「搶先上線日」會換成即將上線的海報，依預約人數由高到低排列，並寫出上線日期。只有還在未來、而且寫得出月日的短劇會出現。再按一次回到原本的發現頁。

「新劇」和「紅果首發」同時成立時，海報只留「紅果首發」。熱度寫在劇名下面。右上角的來源與搜尋留在原位，來源選單的文字與按鈕對齊。熱播榜排在分類上面。
