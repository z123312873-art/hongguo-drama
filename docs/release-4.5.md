# 紅果短劇 4.5

4.5 為 **正式版**（`v4.5` / GitHub Latest）。`windows/4.5-release-*` 分支的 Windows CI 建置後，由 `publish-release-4-5` 工作建立發行：安裝版（NSIS）、`.blockmap`、`latest.yml`（應用內更新必需）與便攜 ZIP。安裝檔未簽章，SHA256 寫在發行說明。發行完成後才刪除 4.5 預發佈（`installer-4.5-traditional-pre`）。已安裝的 4.3 會看到這次更新。

## 更新摘要

- 新增「搶先上線日」顯示即將上線解鎖短劇，請多加利用
- 修正首次播放卡頓問題
- 修正來源格式不同時，優化在線播放等待
- 優化線路不穩時，自動接入備用線路
- 首次安裝程式時，預設改為繁體中文
- 優化線上播放異常問題

發現頁標題旁邊的「搶先上線日」會換成即將上線的海報，依預約人數由高到低排列，並寫出上線日期。寫得出月日、而且日期不是早於今天的短劇會出現。今天和還沒到的日子會留著。再按一次回到原本的發現頁。

「新劇」和「紅果首發」同時成立時，海報只留「紅果首發」。熱度寫在劇名下面。右上角的來源與搜尋留在原位，來源選單的文字與按鈕對齊。熱播榜排在分類上面。
