# 红果短剧 3.1（已正式发布）

内部版本 3.1.0，基于 3.0 正式版。已正式发布，标签 v3.1。本轮未覆盖本机正式安装和用户资料。

## 下一季与搜索

- 按 Issue #45 的场景加入手动“查找下一季”，优先显示已登记档案，再查询当前剧的来源；候选由用户核对后选择，不自动播放。
- 同来源、同基础剧名、更高明确季数才作为续作候选；不将同名跨来源内容当作权威续作关系。
- 主剧名搜索已有同名季度结果时，从第二季起补最小缺失季；手动及后台续作检查从当前季之后补最小缺失季。每次最多补搜中文／数字季名两条；全部来源合并结果按标题相关性排序并去重，保留来源与失败提示。
- 上游可能未收录或未返回某季；未找到不等于不存在，不承诺任意错字纠正或全网搜全。

## 审计修复

- 删除单剧／全部下载文件不再连带清除在线播放缓存或撤销会话；缓存由独立按钮管理。
- 单剧与全部清理共用逻辑，只在文件删除成功后累加释放空间；单集删除同步修正统计。
- 下载任务单删／批删共用保存与回滚逻辑。保存失败时任务记录数不虚报成功，实际删除文件数与释放空间仍返回；界面展示释放结果及保存错误。等待取消期间的并发任务变化不会被旧快照覆盖。
- 清除已确认属于本剧的加密临时文件、历史 concat 列表和空目录。合并产物按登记归属或非共享目录中的精确剧名识别；共享目录中未登记及归属冲突的产物保留，关闭“包含合并产物”时同时保留 concat。保护活动下载、合并及未知归属文件。
- 部分删除失败或调用异常后仍刷新分集、已下载集数、文件数量与空间统计，并显示已删除／失败数量。任务记录保存失败时保留实际删除统计、恢复内存记录并提示保存失败；重试不会重复累计释放量。
- 删除、空间统计、分集列表、合并输入及空档案清理共用归属枚举。共享目录按明确任务或包含剧名的精确档案分集名识别；同名歧义、无剧名模板和跨剧重复路径保守排除。正在合并的剧不计入可释放空间，全部清理遇到运行合并会提示跳过。
- 单任务、批量任务、单集和看完自动清理复用归属检查，连同加密临时文件一起判断。被其他目标外任务或合并产物登记、仍在使用的文件及记录保留，并返回明确提示；只删任务记录的选项仍可单独使用。
- 单集清理同时移除其 `.enc.tmp` 和 `.enc.tmp.decoded`；临时文件删除失败时保留恢复记录。任务取消等待结束后再次检查状态，同一任务被重新激活时保留文件与记录。
- 通过活动任务／合并保护检查并完成文件扫描后，清理会取消目标失败任务的自动重试并保存状态；整剧、全部、单集、自动清理及任务删除入口一致。即使文件删除失败或归属冲突而保留记录，也保存已取消的重试计划；任务提示保留原失败原因并注明需手动重试。扫描因损坏记录抛错时，操作报错并保留原文件和重试状态。
- 代理测试按表单及启动快照解析目标地址，不临时修改全局网络环境；正确处理 HTTP／HTTPS、大小写、ALL_PROXY 和 NO_PROXY。
- 手动模式覆盖环境绕过规则，切回系统模式恢复启动快照。系统模式明确区分接口／下载的环境代理与发现页、浏览器的系统代理。
- 收藏缺档案回退采用 `SERIES_NOT_FOUND`；观看记录续作优先本地档案，缺档案才联网。解析期间离页或重复点击不再触发过期播放重试。明确点播可恢复隐藏档案，保存失败回滚。
- 后台续作检查复用手动入口的同源有界补搜；自定义及未知来源不发起红果续作搜索。部分失败保留本地候选、提示未完成，不更新成功检查时间。
- 下一季查询失败或部分失败且没有候选时，明确显示“查询未完成”，不同时显示“暂未找到”。
