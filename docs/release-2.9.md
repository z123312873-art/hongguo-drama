# 红果短剧 2.9

本轮源码与发行目标为 2.9，包配置为 2.9.0。提供 Mac arm64、Mac x64 和 Windows x64 同源发行资产；实际构建、签名、公证与发布状态以本版发行页为准。

## 新增时间轴弹幕

在 2.8 的快进／回退和控件隐藏修复之上，接入带播放时间点的分时弹幕，快进、回退和切集后重新对齐。保留原来的本集评论来源作为可选备用，显示设置与屏蔽词继续可用。取源失败会显示错误，不会冒充本集无弹幕。

显示区域按字号排列连续轨道，修复全屏、半屏只有几条横带且间距过大的问题；三个密度档均提高投放量。进入、退出全屏时保留并重排正在显示的弹幕，避免清空后等待重新入场。实际数量仍取决于片源在对应时间点提供的弹幕。

匿名客户端标识在本机生成后持续复用，修复每次重启更换标识、导致上游返回的弹幕子集大幅变化。全屏切换期间的短暂停帧与不可见状态也会保留当前弹幕，真实快进、回退和切集仍重新对齐。

退出全屏时恢复原来的页面滚动位置，避免播放器被挤到窗口下方、进度条落到可视区外；按钮退出与 Esc 退出均生效。

## 观看与管理改进

键盘调速、切集、快进、连播与全屏切换保持底栏隐藏状态，普通键和系统音量键不再唤起底栏。暂停、鼠标操作、Tab键盘访问与打开菜单仍正常显示控件。调速后在画面右上角显示当前倍速1.8秒，不占用底部提示。

- 时间轴弹幕优先续用已有安全空位，减少短弹幕被拆散到多行造成的水平空档；时间轴的新内容不提前投放，空档轮播规则见下文。
- 下载管理的更多操作支持外部点击、焦点离开及 Esc 关闭；关闭播放器菜单后恢复播放快捷键，保留菜单按钮的空格和回车操作。
- 观看记录、收藏与上新、搜索历史可逐条移除；收藏展示海报，缺少海报时保留占位。观看记录增加全部／未看完／已看完筛选；以当前最后一集播放结束的记录判断，旧记录缺少完成证据时归入未看完，新集更新后重新归入未看完。
- 单纯进入剧库时等待用户点击，不自动播放或重新缓存上次剧集；明确点播、续播和切集保持原行为。
- 管理按钮在横屏和竖屏均展开实际管理操作；预缓存、自动兼容、看完自动删除移至设置页。
- 剧库列表支持永久移除，不删除视频，也不列入恢复项；观看记录仍可主动续播或重新搜索添加。
- 开启看完自动删除后，先释放本集媒体，再清理本集下载文件、在线缓存和转码缓存；保护下一集缓存和正在执行的下载/准备任务。下载文件删除不可撤销，默认开关不变。
- 官网在 Fake-IP 网络下改用两处固定可信 HTTPS 解析竞速，避免单一解析服务不可达时阻塞；保留 TLS、公网地址和重定向校验。

在线播放继续按格式使用内存或受限临时文件。加密、转码等场景不能保证两集只占 50MB，因此没有强改为纯内存模式。

官网标记为受保护播放的 SEO 公共文件可能仅含约10秒预览；自动播放与下载不再将其当整集，转向现有完整片源回退。完整正片的首次准备仍可能需要下载和解密。

## 连贯观看补充

快进、后退和短暂缓冲时，已有弹幕继续滚动；时间轴仅调整后续投放位置，避免清屏与倒退重复。切换视频或关闭弹幕仍清理旧叠层。鼠标停住1秒后自动隐藏底栏及播放器内指针，键盘播放操作不延长该计时；暂停、菜单、拖动与键盘焦点保留可操作控件。

## 弹幕密度与空档补齐

三档投放频率提高。时间轴弹幕在当前片段供应不足时，轮播已经完整滚出画面的真实内容；新到点内容优先，供应充足时停止补充轮播。本集评论用完后同样补齐空档，新读取的评论优先。轮播遵守屏蔽规则，不重复投放仍在屏上的同一内容；减少动态效果模式保持原有静态展示。从中途续播或重新开启时，如果当前画面和轮播队列都为空，会补入少量已到点的真实历史内容，避免空等下一条；不会提前显示未来时间点的弹幕。没有可用内容时仍显示暂无弹幕。
