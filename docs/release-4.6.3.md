# 紅果短劇 4.6.3 預發佈

預發佈內部版本為 4.6.3，發行標籤為 `installer-4.6.3-traditional-pre`。正式版仍是 4.6.1，更新器不會把預發佈當成最新版；下載與安裝須自行確認。確認沒問題後，再發佈 4.7 正式版。

## 更新摘要

- 觀看紀錄與手機同步更快：定時自動更新
- 觀看紀錄新增批次移除，可全選目前篩選的結果
- 搜尋頁預設來源改為紅果，一次顯示全部搜尋結果
- 搜尋結果分成「標題匹配」與「其他相關」，海報載入更快
- 精簡搜尋頁提示文字，修正來源選單文字偏下

## 說明

觀看紀錄頁登入後每 60 秒向帳號讀取一次，切回視窗時也會更新。在電腦看劇的進度合併後再上傳，關閉程式前會先送出尚未上傳的進度（最多等 3 秒）。移除與同步不會互相搶先。手機何時顯示，取決於紅果手機 App 的更新時機。

觀看紀錄按「批次移除」進入選取模式，可逐部勾選或全選目前篩選的結果。移除會同時從手機帳號刪除，一次最多 100 部，分批進行，可中途停止；失敗的劇會保持勾選，方便重試。帳號讀不到或讀回空清單時不會刪除任何紀錄。

搜尋頁預設來源是紅果，摘要列顯示找到幾部、標題匹配與其他相關各幾部，並自動載入後續頁面（最多 1000 部），沒載完可按「載入更多」。前 24 張海報優先載入，超過 0.6 秒未出現會同時試另一個尺寸。

預發佈用來實測播放與同步。測試時請特別確認影片觀看、續播與手機同步。
