# 红果短剧 3.3（源码／发行目标）

内部版本 3.3.0，基于 3.2 正式版；计划标签 v3.3，尚未发布。当前正式版仍为 3.2。以下记录本轮源码改动，不能替代最终安装包与真实片源验收。

## 下载恢复（Issue #46）

- 红果选择 1080P、720P 后，所选清晰度不可用或传输、解密、媒体验证失败时，尝试来源实际提供的更低清晰度。1080P 失败可继续尝试 720P 及更低片源；不保证来源一定提供可用候选。
- 下载管理显示正在降级及最终低清晰度提示，保存前检查视频轨、实际分辨率和时长；不放大冒充高清。
- 保留已有本地文件，不自动删除或覆盖。下载策略不改变在线播放及第三方来源的取源策略。
- 取消、磁盘空间／权限、安全拦截及本地媒体工具不可用等错误不触发降级。任务失败、停止或重新开始时清除旧降级提示。

## Mac 界面大小

- 「视图」菜单的放大、缩小与实际大小独立保存用户选择；调整窗口、切换横竖布局、退出全屏和重新启动时继续使用。
- 字号只随手动缩放调整，拖动窗口、切换横竖屏和全屏不再改变字号；独立缩放模式避免不同窗口相互影响；同时移除响应式断点与视口宽度驱动的字号覆盖；缩放范围为 50%–200%，每次调整 10%。保存失败会显示错误。

## 发行与验收状态

- 对外版本和文件名使用 3.3，包配置与锁文件使用 3.3.0。保留历史版本、依赖版本和第三方许可正文。
- 源码候选已完成回归、前端构建与随机真实短剧两集下载及短时播放；快进／回退、全屏、切集通过，用户确认声音正常。
- 隔离验收中模拟高画质 HTTP 503 后，同一集从真实片源下载为 720P，界面提示、分辨率、时长及前 10 秒音视频解码通过；这是受控故障验证，不是上游自然缺失的证明。
- Mac 实际窗口验证：窗口大小变化不改变字号；手动缩到 90% 后退出重启仍保持，恢复 100% 正常。补修响应式字号后，实际 1100／906／620 像素窗口与竖屏检查通过，播放器按钮换行且文字完整；最终三端产物仍待打包后核验。
- 构建、Developer ID 签名、Apple 公证、装订、Windows 安装升级、资产摘要与公开发布须分别核验后补记。Windows EXE 未配置代码签名，不宣称已签名。
- 本版修复不保证所有网络、片源和设备上的下载成功；实体 Intel Mac、实体 Windows、干净系统 Gatekeeper 与长期播放的覆盖须单独说明。
