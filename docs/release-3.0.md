# 红果短剧 3.0

3.0 已正式发布，内部版本 3.0.0，基于已发布 2.9。Mac arm64、Mac x64 与 Windows x64 的 16 项资产绑定源码提交 `e53b3e626bc5c1fb935d8980f0dc4b6c3711bda3`。本次发行后文档补充不改变已发布程序与标签。

## 修复范围

- 强制直连和关闭代理时，统一处理继承的 `ALL_PROXY` / `all_proxy`，切回系统模式恢复启动环境，避免窗口与主进程请求代理行为不一致。
- 清除下载任务记录后，删除全部已下载仍按剧集档案定位合集；保留活动任务保护，不扩大到无法确认归属的目录。
- 修复鼠标移出播放器后精确返回原位置时控件未显示；保留静止鼠标、全屏切换和播放快捷键不唤起控件的行为。
- 收藏与上新播放优先使用本地已登记档案，只有缺档案才联网解析；上游不可用时不会阻断已有本地视频的播放入口。

保留 2.9 时间轴弹幕、观看记录、播放器和缓存管理改进；第三方来源与 GPL 声明不变。

## 验证与发行

基于 2.9 先复现再修复：代理与合集新增回归在修复前失败；修复后下载安全检查 27 项、收藏播放入口 8 项通过。发行前单元测试及 71 项平台检查通过，前端构建通过。

首轮 Windows 成品检查发现 2.9 遗留的鼠标回入原位置问题；新增回归先失败后通过，首轮候选未发布，最终三端产物重新构建。

最终提交重新通过 GitHub 单元及 71 项平台检查，双 Mac App 与 DMG 均完成签名、公证 Accepted、装订及更新 ZIP 摘要核验。Windows CI 通过正常视频播放、控件回入、新装、重装、真实官方 1.80 升级及资料保留；EXE 未签名。

Mac arm64 最终成品通过实际收藏入口离线播放、续播、两集各约 10 秒后暂停和真实鼠标同点回入；x64 在 Rosetta 下通过隔离启动、版本和正常退出。实际验收对象与最终更新 ZIP 的程序摘要一致。16 项公开附件大小与 SHA256 均已核对。
