# 紅果短劇 4.7 正式版

正式版內部版本為 4.7.0，發行標籤為 `v4.7`。已安裝的 4.0 以上正式版，以及 4.6.3、4.6.5 預發佈，都會收到更新通知；下載與安裝仍須自行確認。便攜版需手動下載新版。

## 更新摘要

- 修復紅果短劇無法播放
- 修復河馬短劇播放來源
- 河馬短劇海報載入加快
- 優化河馬短劇標籤篩選
- 觀看紀錄與手機同步更快，且可批次移除紀錄
- 搜尋預設紅果，並優化顯示清單
- 精簡提示文字，修正來源選單顯示

## 說明

4.7 整合 4.6.3 與 4.6.5 預發佈的修正：紅果短劇恢復播放；河馬短劇改用可播放的來源，畫質最高 720P；河馬海報換頁不再空白，每頁數量與紅果一致並可直接跳頁；河馬題材標籤整理成複合分類；觀看紀錄與手機同步更快並可批次移除；搜尋預設紅果並整理結果清單；精簡提示文字並修正來源選單顯示。

更新器只讀取本倉庫標為最新的正式版與其 `latest.yml`，不會提示預發佈。4.0 安裝版的更新視窗只顯示前四行摘要，其餘版本顯示全部七行。
