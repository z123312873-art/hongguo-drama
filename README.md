## 致敬原倉庫

這個專案改自 [jackotom/hongguo-drama](https://github.com/jackotom/hongguo-drama)。謝謝原作者把紅果、西飯、河馬的搜尋、播放、下載、追劇和合併，做成可以在電腦上使用的開源桌面程式，並以 GPL-3.0 公開。

這裡不是另一套播放器，而是在那份程式上繼續改。播放、下載與媒體處理的主體仍來自上游；本倉庫負責繁體化、後續修正，以及自己的 Windows 安裝檔。上游的發行頁、版本紀錄與問題討論仍在 [jackotom/hongguo-drama](https://github.com/jackotom/hongguo-drama/releases)。

更早的基礎還包括 [327044572/hongguo-downloader](https://github.com/327044572/hongguo-downloader) 與 [zhenyong97/hongguo-downloader](https://github.com/zhenyong97/hongguo-downloader)。時間軸彈幕的取得與投放參考 [dawei233/hongguo-drama](https://github.com/dawei233/hongguo-drama) 的提交 `c884fab6c6e36ad38173e251738b9b35f958383f`，同樣沿用 GPL-3.0。

## 繁體化與版本

此倉庫的介面預設繁體中文。之後的 README、發行說明與安裝頁都用繁體撰寫，不再改回簡體。

視窗右上角可以在繁體與簡體之間切換。轉換只作用在畫面上的文字。搜尋框、檔名、下載目錄和選單的值不會被改寫。送給紅果搜尋時，會另外把繁體關鍵字轉成簡體再查，找到的劇名仍依目前介面顯示。

## 下載與安裝

這個倉庫只發行 **Windows x64** 安裝檔。媒體工具已內建，不需要另外安裝 Node.js 或 FFmpeg。

**[下載 3.3 正式版（Windows x64）](https://github.com/z123312873-art/hongguo-drama/releases/download/v3.3/hongguo-downloader-3.3-win-x64-setup.exe)**

- 依精靈安裝。預設目錄是 `C:\hongguo`，安裝時可以改。已安裝的 2.9 會收到這個正式版的更新提醒；下載和安裝仍要自己確認。
- 安裝檔未簽章，系統可能出現安全提示。請從 [3.3 正式版頁](https://github.com/z123312873-art/hongguo-drama/releases/tag/v3.3) 下載，並對照該頁的 SHA256。
- 一般使用只需要這個安裝檔。發行頁裡的 `latest*.yml`、`.blockmap` 給更新程式用；Source code 是原始碼，不能直接執行。
- 從 2.9 或更舊的程式換過來時，先退出舊程式再安裝。設定、觀看紀錄與已下載的影片留在原來的資料目錄。上一版正式安裝檔仍在 [2.9 正式版](https://github.com/z123312873-art/hongguo-drama/releases/tag/installer-2.9-traditional)。
- 3.4 是預發布，不會取代 3.3 的自動更新。想先試搜尋、下一季接播、劇評與預設最大化，用 [3.4 預發布](https://github.com/z123312873-art/hongguo-drama/releases/tag/installer-3.4-traditional-pre) 的 `hongguo-downloader-3.4-win-x64-setup.exe`，並對照該頁 SHA256。

## 開始使用

1. 打開「設定」，確認下載目錄後儲存。
2. 在「發現短劇」瀏覽，或在「搜尋與下載」輸入劇名、紅果分享連結或劇集編號。
3. 開啟詳情後按「立即播放」。要存檔時，再自行勾選集數與清晰度加入下載。
4. 下次從「我的劇庫」或「觀看紀錄」接著看。下載進度、失敗重試與整劇合併在「下載管理」。

## 這個版本做了什麼

3.4 預發布在 3.3 正式版上補了搜尋、下一季接播、劇評與視窗。正式版自動更新仍停在 3.3。

- **搜尋**：紅果改走公開搜尋介面，並同時嘗試 App 搜尋。頁面嗅探只在介面格式變更時才用。繁體關鍵字會轉成簡體再查，搜尋框原文保留。西飯、河馬與自訂來源的查詢方式不變。
- **下一季**：某一季的最後一集開始播放時，背景查找緊接的下一季，畫面上不提示。這一集播完後，播放器中央顯示下一季海報與名稱，倒數 5 秒再播放第 1 集。繁體介面顯示繁體劇名。只有下一季，不會從第一季跳到第五季。
- **劇評**：公開劇評改讀詳情頁。鎖定分集不再跟著播放頁的 HTTP 302 失敗。當前集評論改走評論列表。查找下一季按鈕移到劇名旁，切換短劇移到「我的劇庫」右側。
- **視窗**：打開時預設最大化。

這一版以原本的繁體 2.9 為底，只併入上游 3.0 到 3.3 裡測起來更好、而且不會改掉既有行為的部分。

- **下載**：紅果片源在所選 1080P 或 720P 不可用、傳輸或檢查失敗時，會依序嘗試來源實際提供的更低清晰度，並在下載管理顯示結果。取消、磁碟、權限與本機媒體工具錯誤不會因此改抓低畫質。已有檔案保留。在線播放仍按所選清晰度取源；標成高畫質但實際畫面較小的分集，繼續播放實測畫面，不把整集判失敗，也不改掉下一集的選擇。
- **片單**：發現頁與熱播先顯示已經拿到的清單。重新整理逾時、失敗或空結果時留下原內容，不會把選中的劇跳回第一部。
- **發現頁橫幅**：紅果「發現短劇」頂部依綜合熱播榜現時熱度，由高到低輪播最多 10 部。每 5 秒由右往左換下一部，滑鼠停在橫幅上會暫停。海報鋪滿橫幅並從左側漸進融入底色。播放只開啟詳情，不會下載。分類、篩選與海報排在橫幅下面，海報少兩橫排；1K、2K、4K 都至少留一橫排。側欄不再單列「熱播推薦」。西飯、河馬與自訂來源不顯示這條橫幅。
- **播放與收藏**：滑鼠移出播放器後回到同一點，控制列仍會出現。收藏與上新若已有本機劇集檔案，斷網時仍可開啟。強制直連會一併清掉繼承的 `ALL_PROXY`。
- **清理與下一季**：刪除下載檔不再順便清掉線上播放快取。清理會核對檔案歸屬，進行中的下載與合併會留下。可以手動查找下一季，候選要自己確認，不會自動播放。
- **沒有整包換掉的部分**：繁體介面、字級、雙彈幕、切換短劇的位置、預設安裝目錄，以及只檢查本倉庫正式版，都留在這個版本。Mac 的檢視縮放有接上，預設是 100%，不會改掉設定裡的字級。

相對上游 2.9，這個繁體版原本另外處理了這些事：

- **繁體介面**：預設繁體，可切回簡體。側欄、分類、工具列、頁尾與熱播標題會跟著設定裡的介面字級變大。頁尾標示為紅果短劇（Tanney）。
- **彈幕**：先讀帶時間點的時間軸彈幕，時間到了才出現。時間軸不夠 25 條時，用本集評論補到大約 25 條；時間軸更多就不再補，並且一集最多播放 35 條，多出來的按整集時間均勻留下。本集評論的出場間隔和速度會變動，不綁固定秒數；跟時間軸同一行時改成相同速度，避免互相蓋住。飛出畫面後不再循環重播。本集評論改走評論列表介面，公開網頁轉走的後面集數也能補；介面失敗時才退回公開頁的部分評論。讚、送花這類寫在方括號裡的表情，會顯示成 emoji。不再手動選彈幕來源。時間軸介面失敗時停在時間軸，可以重試。
- **清晰度**：自動、720P、1080P 的選擇會保留。在線播放某一集片源不夠時，只改播該集實際畫面，下一集仍用原來的選擇重新取源。不會把較小的畫面標成 1080P。紅果下載則會在所選畫質失敗時嘗試更低清晰度。
- **發現頁**：不再單列圖文「漫畫」。那是上游的圖文空頁，不能當影片播放或下載。動態漫畫請選「漫劇」。
- **紀錄與劇庫**：觀看紀錄可以單部移除，並用全部、未看完、已看完篩選。劇庫可以永久移除一部劇。
- **安裝位置**：Windows 安裝版預設 `C:\hongguo`。

片源、清晰度與可用集數仍以來源實際回傳為準。軟體不保證每一集都有 1080P，也不保證彈幕數量與手機端完全相同。

### 找劇

- 預設同時查詢紅果、西飯與河馬，結果會標明來源。某個來源失敗時，其餘來源仍會顯示。
- 發現頁有海報、劇名、集數、題材篩選與分頁。紅果分類為真人劇、漫劇、AI 劇，另有綜合、真人、漫劇、AI 四類熱播榜。紅果發現頁頂部另以綜合熱播榜前 10 名輪播，每 5 秒換一部。
- 可貼上紅果分享連結或劇集編號。詳情頁可以立即播放，也可以勾選集數下載。
- 選集支援單選、多選、全選、反選，以及 `1-30`、`1,3,5`、`1,5,10-20` 這類範圍。

| 來源 | 已做到 | 邊界 |
|---|---|---|
| 紅果 | 目錄、題材、四類熱播榜、搜尋、分享連結與編號、可播放分集的線上播放與下載 | 網頁沒有片源時會再嘗試取址，結果仍以來源回傳為準 |
| 西飯 | 獨立目錄、題材、分頁、搜尋、已開放分集的播放與下載 | 熱播榜尚未接入；鎖定的分集會跳過 |
| 河馬 | 官網目錄、題材、前後翻頁、搜尋、分集列表、明確免費分集的播放與下載 | 收費或狀態不明的分集保持鎖定，不提供解鎖 |

檔案按來源與劇名分資料夾儲存。

### 播放

- 已下載的分集直接播本機檔案。未下載且未鎖定的分集嘗試線上播放。
- 可暫停、拖動進度、調整音量，倍速從 0.25× 到 4×。
- 「快取下一集」預設開啟。目前這集開始播放後，會預先準備下一個可播放的分集。
- 自動連播預設開啟，會跳過鎖定的分集。
- 斷點按劇儲存集數與播放位置。切到應用裡的其他頁面時，仍可繼續播放。
- 解碼失敗或黑畫面有聲音時，可轉成 H.264 再播。相容模式預設開啟。
- 線上播放不寫入下載目錄，但準備片源與轉碼仍可能暫時使用磁碟空間。

優先選較易播放的 H.264。同一種編碼裡再看清晰度，所以畫質有時會低於 HEVC 的最高解析度。

### 畫面與視窗

- 頂端可切換橫屏版與豎屏版。切回橫屏時，會恢復先前的視窗大小與位置。
- 可以置頂。豎屏時選集欄可收合，也可以隱藏不常用的按鈕。
- 全螢幕或豎屏播放時，控制列閒置約 1 秒會隱藏。移動滑鼠可以再叫出來。暫停、拖動進度、開啟選單，或鍵盤焦點停在控制項上時，控制列保持可見。
- 畫面模式按每部劇分開記憶，可選「適應視窗」或「保持寬度」。

### 觀看紀錄與追更

- 真正開始播放後才寫入觀看紀錄，按最近觀看排序。
- 可以單部移除，也可以用全部、未看完、已看完篩選。
- 應用執行期間，大約每 6 小時檢查已看劇集有沒有新的一集。同名、季數更高的疑似續作大約每天檢查一次，可能誤判或漏掉。
- 系統通知預設關閉。紀錄只存在這臺電腦，沒有跨裝置同步。

### 下載、合併與劇庫

- 下載清晰度可選自動（相容優先）、1080P、720P，並可存成預設值。選源時看實際畫面尺寸。紅果片源達不到所選尺寸，或傳輸、檢查失敗時，會嘗試更低清晰度並提示；不會把較小的檔案標成 1080P，也不會把畫面放大冒充高畫質。已有檔案不會被蓋掉。
- 同時下載 1 到 10 個，預設 3 個。較高的並行數可能被來源限流。
- 失敗任務可以重試或停止。重試不一定能從已下載的位元組續傳。
- 合併整部劇只處理已下載的分集，不會自動補齊缺集。可選較快的拼接，或輸出 H.264/AAC。原始分集會保留。
- 劇庫可以移除清單但保留檔案，也可以刪除已下載的影片。看完自動刪除預設關閉；想長期留片就不要開啟。

### 設定、網路與更新

- 下載位置、檔名規則、代理與各項提醒都在「設定」。代理可跟隨系統或環境變數、手動指定 HTTP/HTTPS，或強制直連。
- 「跟隨系統」主要讀取 `HTTP_PROXY`、`HTTPS_PROXY` 等環境變數，不保證認得所有系統代理或 PAC。
- 自動檢測更新預設開啟，大約每 6 小時查一次本倉庫的正式版。右上角提醒可以關掉。未按下載就不會抓安裝檔，也不會在退出時自動安裝。

### 外觀、收藏與彈幕

- 外觀可選淺色、深色或跟隨系統。隱身小窗在滑鼠移開時暫停並隱藏，移回後繼續。
- 收藏只存在本機。「收藏與上新」依照已瀏覽劇集的公開日期整理，不是完整的未來上新表。
- 畫面增強有原畫、可調銳化，以及面向動畫的 Anime4K。它不改寫已下載的檔案。
- 彈幕可調不透明度、字級、速度、區域與密度。內建常見敏感詞過濾，也可以自訂遮蔽詞。不能發送或回覆彈幕，也沒有帳號登入與跨裝置同步。

## 播放快捷鍵

| 按鍵 | 動作 |
|---|---|
| `空白鍵` | 播放／暫停 |
| `←`／`→` | 後退／前進 5 秒 |
| `↑`／`↓` | 上一集／下一集 |
| `A` | 開啟／關閉連播 |
| `S`／`D` | 降低／提高 0.25 倍速 |
| `F` | 切換全螢幕 |
| `Esc` | 退出豎屏填滿視窗，或關閉目前的選單 |

預設按鍵可在「設定」裡修改，支援單鍵或 Shift 組合，也會檢查衝突。輸入框、選單與對話方塊不會誤觸播放快捷鍵。

## 常見問題

### 為什麼有些分集鎖定，或清晰度不一樣？

片源與可用範圍由來源服務決定。西飯的鎖定集、河馬的收費或狀態不明分集都會保持鎖定。這個程式不提供解鎖。來源介面可能改變，以前能播不代表以後一直能播。

### 下載失敗或目錄載入不出來怎麼辦？

先看網路與來源平臺是否正常，再看代理開關與模式，並把並行下載數調低。可以重試失敗任務，或重新載入目錄。黑畫面但有聲音時，試試相容模式。

### 影片、設定與紀錄放在哪裡？

影片在設定裡的下載目錄，按來源與劇名分資料夾。設定、任務與觀看紀錄在 Windows 上預設位於 `%APPDATA%\hongguo-downloader\`。

若自行指定使用者資料目錄，以該位置為準。從劇庫移除、刪除任務紀錄、刪除影片與清理快取是不同操作，請看確認框再按。

### 怎樣更新？

Windows x64 安裝版預設檢查本倉庫的正式版。出現較新的正式版時，先由你決定是否下載，下載完成後再由你決定是否重新啟動安裝。預發布不會提示。從 3.3 起，正式版發行說明若寫成「摘要：」再接幾行短條列，更新提醒會逐條顯示，不會收成一整句。已安裝的 2.9 只會看到有新版本，不會顯示這些條目。

### Windows 裝了新版，為什麼還是舊版本？

先退出所有正在執行的紅果短劇，再執行 `hongguo-downloader-3.3-win-x64-setup.exe`，並從安裝程式建立的捷徑啟動。不要沿用以前的舊捷徑。設定頁顯示的版本號才是目前執行的版本。

### 自己建置也有簽章嗎？

沒有。自行建置的 Windows 安裝檔不會自動簽章。不需要為了這個程式關閉整個系統的安全檢查。

### 如何回報問題？

請到本倉庫的 [Issues](https://github.com/z123312873-art/hongguo-drama/issues)，寫上應用版本、作業系統、來源、重現步驟與錯誤提示。截圖與紀錄請先去掉帳號、Cookie、代理密碼與個人路徑。上游程式本身的問題，也可以看 [jackotom/hongguo-drama 的 Issues](https://github.com/jackotom/hongguo-drama/issues)。

## 從原始碼建置

應用使用 Electron、React 與 Node.js。需要 Node.js 22.12 或更新版本。

```sh
git clone https://github.com/z123312873-art/hongguo-drama.git
cd hongguo-drama
npm ci
npm test
npm run dev
```

Windows x64 安裝檔使用 `npm run build:installer`。請先備妥對應的 FFmpeg／FFprobe。完整步驟見 [三平臺發行與 Windows 建置說明](docs/RELEASING.md)。自行建置不會自動簽章。

Mac 建置沿用上游流程：`npm run build:mac`。在 Apple Silicon 上，這個指令會產生兩種 Mac 架構。內建的 FFmpeg／FFprobe 來自未修改的 FFmpeg 9.0.2 與 x264 `b35605ace3ddf7c1a5d67a2eb553f034aef41d55`，授權為 GPLv3-or-later。FFmpeg 二進位檔不放進 Git。再散佈編譯結果時，請一併提供對應原始碼與建置材料。

- [macOS 上的 FFmpeg 來源與校驗](build/ffmpeg/MACOS-NOTICE.txt)
- [版本與建置設定](build/ffmpeg/MACOS-VERSIONS.txt)
- [FFmpeg 授權全文](build/ffmpeg/MACOS-LICENSE.txt) · [x264 授權全文](build/ffmpeg/MACOS-X264-LICENSE.txt)
